Project Nova Internal Notes

Project Nova is an internal onboarding platform built by the Platform Engineering team.
It uses a Java Spring Boot backend with a PostgreSQL database, and a React frontend.
Authentication is handled via JWT tokens with a 24-hour expiry, refreshed automatically
by the frontend's Axios interceptor.

The deployment pipeline runs on Jenkins: every merge to main triggers a build, a suite
of unit and integration tests, and a Docker image push to the internal registry.
Deployments to staging are automatic; production deployments require manual approval
from a team lead.

Common onboarding issues reported by new hires:
1. VPN certificate not installed before day one, blocking access to internal repos.
2. Local environment setup taking longer than expected due to missing Java 17 SDK.
3. Confusion about which Slack channel to use for IT support versus HR queries.

The team's on-call rotation is weekly, and incidents are tracked in Jira under the
NOVA-OPS project key. Postmortems are required for any incident rated Sev-1 or Sev-2.
